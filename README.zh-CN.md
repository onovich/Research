## 使用 AI

克隆或下载这个仓库，再用 AI 编程助手打开。你只需要了解两个入口 skill：

- [`$research-to-html`](skills/research-to-html/SKILL.md)：调研一个行业问题，并生成中英文网页版报告。
- [`$research-to-github-pages`](skills/research-to-github-pages/SKILL.md)：检查并将完成的报告发布到 GitHub Pages。

创建报告时，可以直接告诉 AI：

> 使用 `$research-to-html` 调研**「你的行业问题」**，并生成中英文网页版报告。

报告完成后，再告诉 AI：

> 使用 `$research-to-github-pages` 发布这份报告。

如果 AI 无法识别 skill 名称，让它先读取链接中的 `SKILL.md`。
