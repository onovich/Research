## 使用 AI

克隆或下载这个仓库，再用 Codex 打开；仓库内的 skill 会被自动发现：

- [`$research-to-html`](.agents/skills/research-to-html/SKILL.md)：调研一个行业问题，并生成中英文网页版报告。
- [`$research-to-github-pages`](.agents/skills/research-to-github-pages/SKILL.md)：检查并将完成的报告发布到 GitHub Pages。

创建报告时，可以直接告诉 AI：

> 使用 `$research-to-html` 调研**「你的行业问题」**，并生成中英文网页版报告。

报告完成后，再告诉 AI：

> 使用 `$research-to-github-pages` 发布这份报告。

如果使用其他兼容 Agent Skills 的助手，请按该助手的规则安装或打开链接中的 `SKILL.md`。
